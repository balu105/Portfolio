## ✨ Features

- **Responsive Single-Page Design**: Optimized for mobile, tablet, and desktop viewports.
- **Interactive Particle Background**: Built with HTML5 Canvas featuring mouse interaction physics.
- **Dark Mode & Light Mode**: Toggle theme with `localStorage` persistence and dynamic meta color switching.
- **Animated Skill Metrics**: Radial SVG circle progress indicators triggered on scroll.
- **Stats Counter**: Smooth animated number counters for key statistics.
- **Typewriter Effect**: Subtitle animation cycling through core professional specializations.
- **Printable Resume View**: Dedicated printable single-page resume ([resume.html](resume.html)).
- **Deployment Ready**: Standard file hierarchy configured for GitHub Pages, Netlify, and Vercel.

## 🚀 Local Development

You can run the portfolio locally using any static web server:

Using Python:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.

---

## 🌐 Deploying to GitHub Pages

1. Push your latest commits to the `main` branch:
   ```bash
   git push origin main
   ```
2. Navigate to your GitHub Repository **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Set branch to `main` / `root (/)` and click **Save**.
